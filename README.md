# Podman Recipes

Some podman recipes for services I run on `phack.sh` (the Purdue Hackers
server). The services are managed using standard podman/quadlet tools as well as
some simple nushell scripts I wrote.

## Services I am managing/plan to manage

- [My personal CMS](https://github.com/agarmu/cms.git)
- A postgres instance for the CMS
- Caddy (reverse proxy)
- [Miniflux](https://miniflux.app/)
